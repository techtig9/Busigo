# Build history

Per-phase reports from the original BusiGo build, moved here from the repository root during
the Phase 4 clean-up. Twenty-three files at the top level buried `README.md` and
`PRODUCTION_READINESS.md`, which are the two a new contributor actually needs.

They are archived rather than deleted: they record why things were built the way they were,
and that context is not reproducible. Nothing in the application reads them.
